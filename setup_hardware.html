Hardware & Multi-Station Topology Provisioning

Follow this step-by-step setup guide to verify essential core services and register how many computers and mobile devices will be used across your restaurant or store. All secondary registers will automatically inherit these settings.

Step 1: System Installation & Core Services Checklist
Core Prerequisites
1. Dedicated Installation Folder (C:\Impossible_POS)
For full Windows compatibility, the software must reside in a clean root directory at C:\Impossible_POS with complete write permissions.
2. Extract Software ZIP Archive
Extract the entire contents of the release archive into C:\Impossible_POS so that System_Files and startup batch scripts are directly accessible.
3. Desktop Shortcut & Run as Administrator
Create an official desktop shortcut to launch Impossible POS in fullscreen kiosk mode with Administrator privileges for direct ESC/POS hardware printer control.
4. Start Cloudflare Cloud Tunnel Gateway
Enables public HTTPS tunnel to allow customer mobile phones on 4G/5G cellular data to scan order QR codes and join the waitlist without connecting to store Wi-Fi.
5. USB Digital Fingerprint Biometrics Service
Connect the physical USB fingerprint scanner to allow instant cashier clock-in, shift switching, and manager override approvals with zero PIN typing.
